## Full Description (max 4000 chars)
Kids.Talk is a secure, managed VoIP softphone designed specifically to work with the Kids.Talk PBX service. It provides a safe, controlled communication endpoint for your household.

**Guardian Managed**
Kids.Talk is configured and managed entirely by adults (guardians or grandparents) via the Kids.Talk web portal. There are no in-app settings for users to change, no address books to manage, and no way to dial unapproved numbers. 

**Safe Communication**
The app can only make and receive calls to/from endpoints explicitly whitelisted in your household's PBX configuration. It does not connect to the public telephone network, ensuring a closed, safe communication loop.

**Zero Distractions**
Kids.Talk is a dedicated communication tool. It contains absolutely no advertising, no social media integrations, and no analytics tracking. It does one thing: connects your family safely.

**Requirements:**
- An active Kids.Talk household account and PBX subscription.
- The app must be provisioned via the Kids.Talk web portal before first use.

*Note: This application is a client for the Kids.Talk service. It will not function without an active account.*
